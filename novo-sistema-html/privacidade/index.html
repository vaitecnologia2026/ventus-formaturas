3. Quais dados coletamos

3.1 Dados de cadastro e perfil

  • Nome completo
  • E-mail
  • CPF ou CNPJ
  • Telefone
  • Endereço completo (rua, número, complemento, bairro, cidade, estado, CEP)
  • Data de nascimento (quando aplicável)
  • Foto de perfil (quando enviada pelo usuário)

3.2 Dados financeiros

  • Histórico de compras, vendas, comissões e saques
  • Dados de pagamento (processados por adquirentes parceiros — vide seção 7)
  • Chave Pix (para recebimentos, quando aplicável)
  • Dados bancários (para repasse, quando aplicável)

3.3 Dados de uso

  • Logs de acesso (IP, data, hora, navegador/dispositivo)
  • Páginas/telas visitadas
  • Ações executadas dentro do aplicativo
  • Crashes e erros técnicos (para diagnóstico)

3.4 Dados do dispositivo (apps mobile)

  • Modelo do dispositivo, versão do sistema operacional
  • Token de notificações push (FCM/APNs) — para enviar avisos no celular
  • Permissões concedidas (câmera, notificações, etc — apenas quando você autoriza expressamente)

3.5 Documentos de identificação (apenas em fluxos de verificação)

  • RG/CNH (frente e verso)
  • Comprovante de residência
  • Selfie com documento
  • Documentos da empresa (contrato social, comprovante de CNPJ)

5. Com quem compartilhamos seus dados

Compartilhamos dados pessoais com terceiros estritamente necessários para a execução dos serviços:

  • Adquirentes de pagamento: adquirentes autorizados pelo Banco Central (ex.: Asaas) — processamento de cartões, Pix, boletos. Recebem apenas dados necessários para a transação.
  • Provedores de infraestrutura: Railway e Vercel (ex: AWS, Railway, Cloudflare R2) — hospedagem e armazenamento de dados.
  • Serviços de mensageria: Resend (e-mail transacional) (ex: Resend para e-mail, Twilio para SMS, Firebase para push) — envio de notificações.
  • Autoridades públicas: mediante ordem judicial ou requisição legal devidamente fundamentada.

Nunca vendemos seus dados. Não compartilhamos dados pessoais para fins de marketing de terceiros.

7. Seus direitos

Como titular dos dados, você tem o direito de:

  • Acesso: saber quais dados temos sobre você
  • Correção: atualizar dados incompletos ou desatualizados
  • Exclusão: solicitar exclusão de dados desnecessários ou tratados em desconformidade
  • Anonimização/bloqueio: quando aplicável
  • Portabilidade: receber seus dados em formato estruturado
  • Informação sobre compartilhamento: saber com quem seus dados foram compartilhados
  • Revogação de consentimento: quando o tratamento for baseado em consentimento

Para exercer qualquer desses direitos:

  • Via aplicativo: Configurações → Privacidade → Exclusão de conta / Exclusão de dados
  • Via web: https://ventus-fotos.vercel.app/excluir-conta/
  • Via e-mail: vaitecnologialp@gmail.com (resposta em até 15 dias úteis)

8. Segurança

Adotamos medidas técnicas e organizacionais para proteger seus dados:

  • Criptografia em trânsito (HTTPS/TLS 1.3) e em repouso (AES-256)
  • Autenticação multi-fator (MFA) opcional para usuários
  • Controle de acesso baseado em função (RBAC) para equipe interna
  • Monitoramento contínuo de tentativas de acesso não autorizado
  • Backup regular com retenção e plano de recuperação
  • Auditorias periódicas de segurança

Em caso de incidente de segurança que possa comprometer seus dados, comunicaremos você e a Autoridade Nacional de Proteção de Dados (ANPD) conforme exigido pela LGPD.

9. Cookies e tecnologias similares

Utilizamos cookies essenciais (autenticação, sessão) e analíticos (Google Analytics, Firebase Analytics) para melhorar a experiência. Você pode gerenciar cookies pelas configurações do seu navegador. Recusar cookies analíticos não impacta funcionalidades essenciais.

10. Transferência internacional

Alguns dos nossos provedores (ex: AWS, Google Cloud) podem armazenar dados em servidores fora do Brasil. Nesses casos, garantimos que a transferência segue salvaguardas adequadas conforme art. 33 da LGPD (cláusulas contratuais padrão, certificações reconhecidas).

11. Crianças e adolescentes

O aplicativo destina-se a maiores de 18 anos. Não coletamos intencionalmente dados de menores. Se identificarmos cadastro de menor, a conta será excluída imediatamente.

12. Alterações nesta política

Podemos atualizar esta política periodicamente. Mudanças relevantes serão comunicadas:

  • Por notificação no aplicativo ou e-mail (mudanças materiais)
  • Pela atualização da data no topo desta página (mudanças menores)

O uso continuado do serviço após a notificação constitui aceitação tácita das mudanças.
